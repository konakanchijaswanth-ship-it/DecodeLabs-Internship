# Rule-Based Chatbot

## Objective
Create a simple chatbot using Python that responds to predefined user inputs.

## Features
- Greets the user
- Responds to common questions
- Uses if-else decision making
- Runs continuously until the user types "exit"

## Technologies Used
- Python 3

## How to Run
python chatbot.py


## Sample Inputs
- hi
- hello
- how are you
- what is your name
- exit
